Welcome to C++

C++ is one of the most powerful and widely used programming languages. It's the #1 choice for competitive programming because of its speed and rich standard library.

Why C++ for Competitive Programming?

  • Speed: C++ is one of the fastest languages — critical for time limits
  • STL: Built-in data structures & algorithms (sort, search, etc.)
  • Control: Direct memory access and low-level operations
  • Widely Used: Most competitive programmers use C++

Program Structure

  • #include <iostream> — Import input/output library
  • using namespace std; — Use standard namespace
  • int main() { } — Entry point of every program
  • return 0; — Program finished successfully
C++ 
#include <iostream>
using namespace std;

int main() {
    // This is your first C++ program!
    cout << "Hello, World!" << endl;
    
    return 0;  // Program completed successfully
}

// Output: Hello, World!

02

Input & Output (I/O)

Every program needs to communicate with the user. In C++, we use cout to display output and cin to read input.

Output with cout

  • cout << "text"; — Print text to the screen
  • cout << variable; — Print a variable's value
  • cout << endl; — Move to a new line
  • cout << "\n"; — Also a new line (faster!)
  • Chain with <<: cout << "x = " << x << endl;

Input with cin

  • cin >> variable; — Read value from keyboard
  • cin >> a >> b; — Read multiple values
  • Automatically skips whitespace between values
  • Stops reading at whitespace (space, tab, newline)
C++ 
#include <iostream>
using namespace std;

int main() {
    // Output examples
    cout << "Hello!" << endl;       // with endl
    cout << "World!" << "\n";       // with \n (faster)
    cout << "A" << " " << "B" << endl; // chaining
    
    // Input examples
    int age;
    string name;
    
    cout << "Enter your name: ";
    cin >> name;
    
    cout << "Enter your age: ";
    cin >> age;
    
    cout << name << " is " << age 
         << " years old!" << endl;
    
    return 0;
}

/* Sample Run:
Enter your name: Ahmed
Enter your age: 20
Ahmed is 20 years old!
*/

📤 endl vs \n

// endl: flushes the output buffer (slower)
cout << "Hello" << endl;

// \n: just a newline character (faster)
cout << "Hello\n";

// In CP, prefer \n for speed!

📥 Reading Multiple Values 

int a, b, c;

// Read all three at once
cin >> a >> b >> c;

// User can type: 10 20 30
// or press Enter between each

Variables & Data Types

A variable is a named container that stores data in memory. Every variable has a data type that determines what kind of data it can hold and how much memory it uses.

Variable Declaration

  • type name = value; — Declare and initialize
  • type name; — Declare only (may have garbage value)
  • Names must start with a letter or underscore
  • Names are case-sensitive (age ≠ Age)
  • Use meaningful names: totalScore not ts
⚠️ Common Rule: Always initialize your variables! Uninitialized variables contain garbage values — random leftover data from memory.
C++ 
#include <iostream>
using namespace std;

int main() {
    // Integer types
    int age = 20;
    long long population = 8000000000LL;
    
    // Decimal types
    double pi = 3.14159265;
    float temp = 36.6f;
    
    // Character & Boolean
    char grade = 'A';
    bool isPassed = true;
    
    // String
    string name = "Ahmed";
    
    // Display all
    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Grade: " << grade << endl;
    cout << "Pi: " << pi << endl;
    cout << "Passed: " << isPassed << endl;
    
    return 0;
}

/* Output:
Name: Ahmed
Age: 20
Grade: A
Pi: 3.14159
Passed: 1
*/

04

Operators

Operators are symbols that tell the compiler to perform specific operations. C++ supports arithmetic, comparison, logical, and assignment operators.

🔢 Arithmetic Operators

+
Addition
7 + 3 = 10
-
Subtraction
7 - 3 = 4
*
Multiplication
7 * 3 = 21
/
Division
7 / 3 = 2 (int!)
%
Modulus
7 % 3 = 1
C++ — Arithmetic 
#include <iostream>
using namespace std;

int main() {
    int a = 17, b = 5;
    
    cout << "a + b = " << a + b << endl;  // 22
    cout << "a - b = " << a - b << endl;  // 12
    cout << "a * b = " << a * b << endl;  // 85
    cout << "a / b = " << a / b << endl;  // 3 (integer!)
    cout << "a % b = " << a % b << endl;  // 2 (remainder)
    
    return 0;
}
⚠️ Integer Division: When you divide two int values, the result is also an int! The decimal part is truncated (cut off), not rounded.

7 / 2 = 3 (not 3.5!)
1 / 3 = 0 (not 0.333!)

To get decimal results, cast to double first.
💡 Modulus Tip: The % operator gives the remainder of division. Very useful for:
  • Checking even/odd: n % 2 == 0
  • Getting last digit: n % 10
  • Wrapping around: i % arraySize

⚖️ Comparison & Logical Operators

C++ — Comparison 
#include <iostream>
using namespace std;

int main() {
    int x = 10, y = 20;
    
    // Comparison operators (return true/false)
    cout << (x == y) << endl;  // 0 (false)
    cout << (x != y) << endl;  // 1 (true)
    cout << (x < y)  << endl;  // 1 (true)
    cout << (x > y)  << endl;  // 0 (false)
    cout << (x <= y) << endl;  // 1 (true)
    cout << (x >= y) << endl;  // 0 (false)
    
    return 0;
}
C++ — Logical 
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    double gpa = 3.5;
    
    // AND: both conditions must be true
    bool eligible = (age >= 18) && (gpa >= 3.0);
    cout << "Eligible: " << eligible << endl; // 1
    
    // OR: at least one must be true
    bool bonus = (gpa >= 3.8) || (age < 19);
    cout << "Bonus: " << bonus << endl;     // 0
    
    // NOT: flips true ↔ false
    bool notEligible = !eligible;
    cout << "Not: " << notEligible << endl;  // 0
    
    return 0;
}

✏️ Assignment Operators

C++ — Assignment Shortcuts 
int x = 10;

x += 5;   // x = x + 5  → x = 15
x -= 3;   // x = x - 3  → x = 12
x *= 2;   // x = x * 2  → x = 24
x /= 4;   // x = x / 4  → x = 6
x %= 4;   // x = x % 4  → x = 2

// Increment & Decrement
x++;      // x = x + 1  → x = 3

Type Casting & Precision

Type casting is converting a value from one data type to another. This is crucial in competitive programming to avoid bugs like integer division errors and overflow.

Two Types of Casting

  • Implicit (Automatic): Compiler does it for you when safe (int → double)
  • Explicit (Manual): You force it with (type)value

Precision with fixed & setprecision

  • #include <iomanip> — Required header
  • fixed — Use fixed-point notation
  • setprecision(n) — Show n decimal places
  • Combine: cout << fixed << setprecision(2);
C++ 
#include <iostream>
#include <iomanip>  // for setprecision
using namespace std;

int main() {
    // Integer division problem
    int a = 7, b = 2;
    cout << "int:    " << a / b << endl;      // 3 ❌
    cout << "double: " << (double)a / b << endl; // 3.5 ✅
    
    // Implicit casting (automatic)
    int x = 10;
    double y = x;   // int → double (safe)
    cout << "y = " << y << endl;  // 10.0
    
    // Explicit casting
    double pi = 3.14159;
    int truncated = (int)pi;  // Cuts decimal
    cout << "truncated = " << truncated << endl; // 3
    
    // Precision control
    double price = 19.999;
    cout << fixed << setprecision(2);
    cout << "Price: $" << price << endl; // $20.00
    
    cout << fixed << setprecision(4);
    cout << "Pi: " << 3.14159265 << endl; // 3.1416
    
    return 0;
}

🔧 Explicit Casting Methods

1

C-Style Cast — (type)value

int a = 7, b = 2;
double result = (double)a / b;     // 3.5 ✅

double pi = 3.14159;
int truncated = (int)pi;           // 3 (cuts decimal)

char ch = (char)65;                // 'A' (ASCII)
int ascii = (int)'A';             // 65
💡 Most common in CP! Simple and quick. Use this in contests.
2

C++ Style Cast — static_cast<type>(value)

int a = 7, b = 2;
double result = static_cast<double>(a) / b;  // 3.5

double pi = 3.14159;
int truncated = static_cast<int>(pi);         // 3

// Safer and more readable than C-style
// Compiler checks for valid conversions
⚠️ Note: static_cast is the "proper" C++ way. More verbose but safer. Both work in CP.
3

String → Number — stoi, stod, stoll

#include <string>   // Required
using namespace std;

string s1 = "42";
string s2 = "3.14";
string s3 = "1000000000000";

int    num1 = stoi(s1);     // "42"   → 42       (string to int)
double num2 = stod(s2);     // "3.14" → 3.14     (string to double)
float  num3 = stof(s2);     // "3.14" → 3.14f    (string to float)
long long num4 = stoll(s3); // → 1000000000000LL  (string to long long)

// ⚠️ Throws exception if string is not a valid number!
4

Number → String — to_string()

#include <string>
using namespace std;

int x = 42;
double pi = 3.14;
long long big = 1000000000000LL;

string s1 = to_string(x);     // "42"
string s2 = to_string(pi);    // "3.140000" (default 6 decimals)
string s3 = to_string(big);   // "1000000000000"

// Useful for concatenating numbers with strings
string msg = "Score: " + to_string(95);  // "Score: 95"
5

Char ↔ Int — ASCII Tricks

// char is actually a small integer (ASCII value)
char ch = 'A';
int ascii = ch;          // 65 (implicit)
int ascii2 = (int)ch;    // 65 (explicit)

// Convert digit char to actual number
char digitChar = '7';
int digit = digitChar - '0';   // '7' - '0' = 55 - 48 = 7 ✅

// Convert number to digit char
int num = 5;
char numChar = num + '0';      // 5 + 48 = 53 = '5' ✅

// Convert lowercase ↔ uppercase
char lower = 'a';
char upper = lower - 32;       // 'a' - 32 = 'A'
char upper2 = lower - 'a' + 'A';  // More readable ✅
💡 CP Essential! The char - '0' trick is used in almost every competitive programming problem involving digits!

💥 Overflow — The Silent Bug

C++ — Overflow Example 
#include <iostream>
using namespace std;

int main() {
    // int max: ~2.1 billion
    int a = 1000000;        // 10^6
    int bad = a * a;        // 10^12 → OVERFLOW! 💥
    cout << "Bad: " << bad << endl;  // Garbage!
    
    // Solution: use long long
    long long good = (long long)a * a;
    cout << "Good: " << good << endl; // 1000000000000 ✅
    
    // Or declare as long long from start
    long long b = 1000000LL;
    long long result = b * b;  // Safe!
    
    return 0;
}

When to Use long long?

If the result can exceed 2 × 10⁹, use long long!

int max: ~2.1 × 10⁹
long long max: ~9.2 × 10¹⁸
💡 CP Rule of Thumb:
  • Read the constraints in the problem
  • If n ≤ 10⁹ → result might be 10¹⁸ → use long long
  • When in doubt, use long long
  • Add LL suffix: 1000000000LL

🏆 Challenge: Fix the Code

This code has bugs. Can you fix them to get the correct output?

// BUGGY CODE — Fix me!
int total = 100;
int count = 3;
int average = total / count;   // Bug 1: Should be double
cout << "Average: " << average << endl;  // Prints 33 instead of 33.33

int x = 100000;
int squared = x * x;          // Bug 2: Overflow!
cout << "Squared: " << squared << endl;
Click to see solution 
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    // Fix 1: Use double for average
    int total = 100;
    int count = 3;
    double average = (double)total / count;  // Cast to double!
    cout << fixed << setprecision(2);
    cout << "Average: " << average << endl;  // 33.33 ✅
    
    // Fix 2: Use long long for large multiplication
    long long x = 100000LL;
    long long squared = x * x;  // No overflow!
    cout << "Squared: " << squared << endl;  // 10000000000 ✅
    
    return 0;
}
