01

Conditional Statements

In programming, computers make decisions using conditional statements. They evaluate Boolean expressions (true or false) to decide which block of code to run.

1️⃣

if Statement

Executes a block of code only when its condition evaluates to true.

2️⃣

if-else Statement

Provides two alternate pathways: one for true, and an alternate fallback for false.

3️⃣

else if Ladder

Tests multiple conditions sequentially until the first true condition is met.

C++ — If-Else Ladder & Curly Braces 
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;

    // Else-If Ladder
    if (score >= 90) {
        cout << "Grade: A\n";
    } else if (score >= 80) {
        cout << "Grade: B\n";
    } else if (score >= 70) {
        cout << "Grade: C\n";
    } else if (score >= 60) {
        cout << "Grade: D\n";
    } else {
        cout << "Grade: F (Failed)\n";
    }

    // Nested If statements
    if (score >= 60) {
        if (score == 100) {
            cout << "Perfect score bonus! 🌟\n";
        }
    }

    return 0;
}

🔑 Curly Braces { } & Execution Flow

If you omit curly braces, only the single immediately following statement belongs to the if. In competitive programming, always use curly braces or be extremely vigilant about indentation traps!

⚠️ The "Dangling Else" Trap

An else always pairs with the closest preceding unpaired if within the same scope:

// BAD: Visual indentation does NOT control grouping!
if (x > 0)
    if (y > 0) cout << "Both positive\n";
else 
    cout << "x is negative?"; // BUG! This else pairs with (y > 0)!

❌ Common Mistake: = instead of ==

if (x = 5) performs an assignment! The expression evaluates to 5 (truthy), so the branch will ALWAYS run!

// WRONG:
if (x = 5) {
    cout << "Always executes!";
}

✅ Correct Solution: Equality Comparison

Always use double equals == for testing equality.

// CORRECT:
if (x == 5) {
    cout << "Executes only if x is 5";
}

❌ Semicolon Immediately After if(...)

if (x > 10); // <-- Accidental empty statement!
{
    cout << "This runs regardless of x!";
}

❌ Chained Comparisons (Math Style)

// WRONG in C++:
if (10 < x < 20) // Evaluates (10 < x) to 0 or 1, then checks 0/1 < 20!

// CORRECT in C++:
if (x > 10 && x < 20) // Logical AND ✅
02

The Ternary Operator

The ternary operator ? : is the only three-operand operator in C++. It provides a concise, inline way to choose between two values.

Syntax: condition ? value_if_true : value_if_false

It acts like a value expression, allowing you to embed decisions directly into variable declarations, return statements, or cout streams.

💡 Pro CP Usage: Outputting YES / NO

Instead of writing 5 lines of if-else, competitive programmers frequently write:

cout << (n % 2 == 0 ? "YES\n" : "NO\n");

Note: Always wrap the ternary expression in parentheses when feeding it into cout << because << has higher operator precedence than ?:.

C++ — Ternary Operator Examples 
#include <iostream>
using namespace std;

int main() {
    int a = 15, b = 27;

    // Finding maximum of two numbers
    int maxVal = (a > b) ? a : b;
    cout << "Max: " << maxVal << "\n";

    // Direct output formatting
    int n;
    cin >> n;
    cout << (n % 2 == 0 ? "EVEN" : "ODD") << "\n";

    // Nested ternary (use sparingly for readability)
    string status = (n > 0) ? "Positive" : (n < 0) ? "Negative" : "Zero";
    cout << status << "\n";

    return 0;
}
03

The switch Statement

The switch statement is a multi-way branch statement that compares a single variable or integral expression against constant values called case labels.

C++ — Simple Calculator with Switch 
#include <iostream>
using namespace std;

// Solves Assiut Sheet 1 - Problem C / Mathematical Expression
int main() {
    long long a, b;
    char op;
    cin >> a >> op >> b;

    switch (op) {
        case '+':
            cout << (a + b) << "\n";
            break; // Essential! Exits the switch
        case '-':
            cout << (a - b) << "\n";
            break;
        case '*':
            cout << (a * b) << "\n";
            break;
        case '/':
            if (b != 0) cout << (a / b) << "\n";
            else cout << "Error: Division by zero\n";
            break;
        default:
            cout << "Invalid Operator\n";
    }

    return 0;
}

When to use switch vs if-else?

  • Use switch when testing a single integral variable (int, char, enum) against discrete, constant values.
  • Use if-else for range checks (x >= 10 && x <= 50), floating point values (float, double), strings, or complex compound conditions.

⚠️ The Fall-Through Bug (Missing break)

If you forget break; at the end of a case, execution falls through and executes the subsequent cases even though their condition did not match!

Condition-Based Problem Solving

Every competitive programmer must master these foundational problem-solving building blocks:

1. Positive, Negative, or Zero

if (x > 0) cout << "POSITIVE";
else if (x < 0) cout << "NEGATIVE";
else cout << "ZERO";

2. Even or Odd

if (n % 2 == 0) 
    cout << "EVEN";
else 
    cout << "ODD";

3. Checking Divisibility

// Is A a multiple of B?
if (a % b == 0 || b % a == 0)
    cout << "Multiples";
else
    cout << "No Multiples";

4. Max of 3 Numbers

int a, b, c;
cin >> a >> b >> c;
int mx = max(a, max(b, c));
int mn = min(a, min(b, c));

5. In-Range Verification

// Belongs to [L, R] inclusive
if (x >= L && x <= R) {
    cout << "Inside Range";
}

6. Character Classification

if (ch >= '0' && ch <= '9') cout << "DIGIT";
else if (ch >= 'A' && ch <= 'Z') cout << "CAPITAL";
else if (ch >= 'a' && ch <= 'z') cout << "SMALL";

🏆 Challenge 1: Codeforces 4A — Watermelon

One hot summer day Pete and his friend Billy decided to buy a watermelon of weight $w$ kilos. They want to divide it so that each of the two parts weighs an even number of kilos. Can they divide it?

View Solution & Mathematical Analysis

Analysis: For both parts to be even, the total sum must be even (w % 2 == 0). However, if $w = 2$, the only division is $1 + 1$ (which are odd!). Therefore, $w$ must be even AND greater than 2.

#include <iostream>
using namespace std;

int main() {
    int w;
    cin >> w;
    if (w > 2 && w % 2 == 0) {
        cout << "YES\n";
    } else {
        cout << "NO\n";
    }
    return 0;
}

Introduction to Loops

Why do we need loops? Imagine printing numbers from 1 to 100,000 or summing all inputs from a contest problem. Writing lines manually is impossible. Loops allow instructions to repeat automatically while conditions are satisfied.

1️⃣

1. Initialization

Sets up the loop counter variable before execution begins (e.g., int i = 1;).

2️⃣

2. Condition

Evaluated before every iteration. If true, the body executes; if false, loop stops.

3️⃣

3. Update (Step)

Modifies the counter variable at the end of each pass (e.g., i++, i += 2).

06

The for Loop

The for loop packs initialization, condition, and update in one single, clean header line. It is the most common loop used in competitive programming when the number of iterations is known in advance.

C++ — For Loop Variations 
#include <iostream>
using namespace std;

int main() {
    int n = 5;

    // 1. Counting from 1 to N
    cout << "1 to N: ";
    for (int i = 1; i <= n; i++) {
        cout << i << " ";
    }
    cout << "\n";

    // 2. Counting Backward (N down to 1)
    cout << "Backward: ";
    for (int i = n; i >= 1; i--) {
        cout << i << " ";
    }
    cout << "\n";

    // 3. Different step sizes (Even numbers up to 10)
    cout << "Step by 2: ";
    for (int i = 2; i <= 10; i += 2) {
        cout << i << " ";
    }
    cout << "\n";

    // 4. Powers of two (Multiplying step)
    cout << "Powers of 2: ";
    for (int i = 1; i <= 64; i *= 2) {
        cout << i << " ";
    }
    cout << "\n";

    return 0;
}

Formula for Number of Iterations

For a loop counting with step size $S$ from $Start$ to $End$ inclusive:

Iterations = ⌊(End - Start) / Step⌋ + 1

Example: For for (int i = 3; i <= 15; i += 3):
⌊(15 - 3) / 3⌋ + 1 = (12 / 3) + 1 = 5 iterations (values: 3, 6, 9, 12, 15).

💡 0-Indexed vs 1-Indexed

In arrays and strings, 0-indexing is standard:

for (int i = 0; i < n; i++) // Runs exactly n times: 0 to n-1

For mathematical sequences from 1 to N:

for (int i = 1; i <= n; i++) // Runs exactly n times: 1 to n
07

The while Loop

A while loop continues executing as long as its condition remains true. It is ideal when the number of iterations is unknown in advance (such as processing input until end-of-file, or breaking down a number digit-by-digit).

C++ — While Loop & EOF Reading 
#include <iostream>
using namespace std;

int main() {
    // Example 1: Halving a number until 0
    int n = 40;
    while (n > 0) {
        cout << n << " ";
        n /= 2;
    }
    cout << "\n";

    // Example 2: Reading until End-Of-File (EOF)
    // Critical CP Pattern when input size is not specified!
    int x, sum = 0;
    while (cin >> x) {
        sum += x;
    }
    cout << "Total sum of all inputs: " << sum << "\n";

    return 0;
}

🔑 The while (cin >> x) Idiom

In competitive programming, many problems say: "Input contains several numbers until EOF". The expression cin >> x returns the stream object, which evaluates to false when input runs out. This elegantly reads all data and stops without crashes.

⚠️ Forgetting the Update Step = Infinite Loop!

If the variable involved in the condition is never updated inside the loop body, the condition remains true forever, freezing your program and causing Time Limit Exceeded (TLE)!

08

Loop Control: break & continue

C++ provides two jump statements to alter the natural flow of loops:

🛑 break: Immediate Loop Termination

Immediately breaks out of the innermost surrounding loop. No further iterations will run.

// Stop at first multiple of 7
for (int i = 1; i <= 50; i++) {
    if (i % 7 == 0) {
        cout << "Found: " << i << "\n";
        break; // Exits loop immediately!
    }
}

⏭️ continue: Skip Current Iteration

Skips the remainder of the current iteration body and jumps directly to the update step / next condition check.

// Print odd numbers only by skipping evens
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // Skips printing for evens!
    }
    cout << i << " "; // Prints: 1 3 5 7 9
}
09

Understanding Loop Execution & Tracing

Writing correct loops requires dry-running variables step-by-step. The Trace Table is every programmer's best debugging tool on paper.

Iteration # Variable i Condition Check Operation (sum += i) Variable sum Next Step (i++)
1 1 1 <= 3 → TRUE sum = 0 + 1 1 i becomes 2
2 2 2 <= 3 → TRUE sum = 1 + 2 3 i becomes 3
3 3 3 <= 3 → TRUE sum = 3 + 3 6 i becomes 4
Exit Check 4 4 <= 3 → FALSE Loop Terminates 6 (Final Result) Continues past loop

⚠️ Beware of the Off-by-One Error (OBOE)

The most common bug in competitive programming is running a loop one time too many or one time too few:

  • Checking < instead of <= when bounds are inclusive.
  • Iterating past array boundary: accessing arr[n] when valid indices are 0 to n - 1.

Counters & Accumulators

Patterns you will write in virtually every single competition:

C++ — Counters, Sums, & On-The-Fly Min/Max 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int evenCount = 0;
    long long sum = 0;
    long long product = 1;
    int maxVal = -2e9; // Start at extreme low
    int minVal = 2e9;  // Start at extreme high

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;

        // Counter Pattern
        if (x % 2 == 0) evenCount++;

        // Accumulator Patterns
        sum += x;
        product = (product * x) % 1000000007; // Often with modulo

        // Min/Max on-the-fly without needing an array!
        if (x > maxVal) maxVal = x;
        if (x < minVal) minVal = x;
    }

    cout << "Evens: " << evenCount << "\n";
    cout << "Sum: " << sum << "\n";
    cout << "Min: " << minVal << ", Max: " << maxVal << "\n";

    return 0;
}

💡 Memory Optimization: No Arrays Needed!

Notice that we found the min, max, count, and sum of $N$ values without storing them in an array! This achieves $O(1)$ auxiliary memory space, protecting you from memory limit exceeded errors when $N = 10^6$.

Initial Values for Min & Max

  • For finding Maximum: Initialize to the smallest possible value (-1e9 or INT_MIN).
  • For finding Minimum: Initialize to the largest possible value (1e9 or INT_MAX).
  • Or initialize both with the first element of input.
11

Multiple Test Cases: while (t--)

In modern Codeforces contests, problems usually begin with: "The first line contains an integer $T$ — the number of test cases."

C++ — The Canonical Multi-Test Loop 
#include <iostream>
using namespace std;

void solve() {
    int n;
    cin >> n;
    // CRITICAL: All state must be initialized inside solve()!
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
    }
    cout << sum << "\n";
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int t;
    cin >> t;
    while (t--) {
        solve(); // Executes once per test case
    }

    return 0;
}

💥 The #1 Test-Case Bug: Variable Bleeding

If you declare your accumulators, counters, or arrays globally without resetting them to zero on each test case, the results from test case #1 will contaminate test case #2, causing Wrong Answer (WA) on test 2!

Rule: Re-initialize variables inside the while (t--) loop or dedicated solve() function.

How does while (t--) work?

In C++, the postfix decrement t-- evaluates the condition with the current value of $t$, and then decrements it. When $t$ reaches $0$, $0$ evaluates to false, terminating the loop after running exactly $T$ times.

12

Digit Manipulation (The % 10 and / 10 Duo)

Extracting and peeling digits is tested in dozens of newcomer problems (e.g. Assiut Sheet 2 Problem Q - Digits, Problem I - Palindrome, and Codeforces 977A).

🎯

n % 10 — Extract Last Digit

Returns the remainder when divided by 10, which is always the rightmost digit.
358 % 10 = 8

✂️

n / 10 — Discard Last Digit

Integer division drops the fractional part, slicing off the rightmost digit.
358 / 10 = 35

C++ — Complete Digit Extraction Suite 
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;

    if (n == 0) {
        cout << "Digits count: 1, Sum: 0\n";
        return 0;
    }

    long long temp = abs(n);
    int count = 0;
    int sum = 0;
    long long reversedNum = 0;

    while (temp > 0) {
        int lastDigit = temp % 10;   // 1. Extract last digit
        sum += lastDigit;             // Accumulate sum
        reversedNum = reversedNum * 10 + lastDigit; // Shift & add
        count++;                     // Count digit
        temp /= 10;                  // 2. Remove last digit
    }

    cout << "Digits Count: " << count << "\n";
    cout << "Digits Sum: " << sum << "\n";
    cout << "Reversed Number: " << reversedNum << "\n";

    // Palindrome check: Does original equal reversed?
    if (abs(n) == reversedNum) {
        cout << "It is a Palindrome! ✅\n";
    }

    return 0;
}

💡 Special Corner Case: $N = 0$

If $N = 0$, the condition while (temp > 0) will immediately fail without running, incorrectly reporting 0 digits! Always handle $0$ separately if the problem allows $N \ge 0$.

Extracting Digits in Natural Left-to-Right Order

Because % 10 peels from right-to-left, if a problem requires printing digits from left-to-right separated by spaces, you can either:

  1. Reverse the number first or use recursion.
  2. Read the number as a string: each digit is str[i] - '0'!
13

Nested Loops & Pattern Printing

A nested loop is a loop inside another loop. For every single iteration of the outer loop, the inner loop runs completely from start to finish.

C++ — Understanding Rows & Columns 
#include <iostream>
using namespace std;

int main() {
    int rows = 4, cols = 5;

    // Outer loop controls ROWS
    for (int r = 1; r <= rows; r++) {
        // Inner loop controls COLUMNS in current row
        for (int c = 1; c <= cols; c++) {
            cout << "(" << r << "," << c << ") ";
        }
        cout << "\n"; // End of row newline
    }

    return 0;
}

Total Iterations in Nested Loops

If the outer loop runs $N$ times and the inner loop runs $M$ times, the inner body executes:

Total Operations = N × M

If $N = 1000$ and $M = 1000$, total operations $= 1,000,000$.

💡 Pattern Printing Strategy: The 3 Golden Questions

  1. How many rows? → Controls the outer loop range ($i = 1$ to $N$).
  2. What happens in row $i$? → How many spaces? How many stars/numbers?
  3. Newline: Always print cout << "\n"; immediately after the inner loop finishes each row!

Time Complexity Basics & Avoiding TLE

In competitive programming, your solution must run within the problem's time limit (typically 1.0 second). If your program takes too long, the judge rejects it with Time Limit Exceeded (TLE).

⚡ The CP Golden Rule: ~10⁸ Operations per Second

A standard C++ submission on modern online judges (Codeforces, AtCoder) performs roughly $10^8$ basic operations per second ($100,000,000$).

Notation Name Typical Code Structure Max Safe $N$ for 1.0s Status
O(1) Constant Time Direct math formulas, simple conditions Any size ⚡ Blazing
O(log N) Logarithmic Halving / digit peeling (n /= 10) $10^{18}$ ⚡ Blazing
O(N) Linear Time Single loop from 1 to $N$ $N \le 10^8$ ✅ Excellent
O(N²) Quadratic Time Nested loops (rows and cols up to $N$) $N \le 5,000$ ⚠️ Caution
O(N³) Cubic Time Triple nested loops $N \le 400$ ❌ Slow

Why did you get TLE on $N = 10^5$ with Nested Loops?

If $N = 100,000$ and you write nested loops for (int i=0; i<n; i++) for (int j=0; j<n; j++), the total operations are:

100,000 × 100,000 = 10,000,000,000 (10¹⁰ operations!)

At $10^8$ ops/sec, this will take approximately 100 seconds to run! The judge kills it after 1.0 second with TLE. You must optimize to $O(N)$ or $O(N \log N)$.

15

Common Mistakes & How to Prevent Them

Every competitive programmer makes these mistakes at least once. Study them to save hours of contest time!

❌ Bug 1: Semicolon after loop header

// The loop runs 10 times doing NOTHING!
for (int i = 1; i <= 10; i++); 
{
    cout << "Prints only ONCE with i = 11!\n";
}

✅ Fix: Remove the semicolon

for (int i = 1; i <= 10; i++) {
    cout << "Prints 10 times as intended!\n";
}

❌ Bug 2: Integer Overflow in Accumulator

int n = 100000;
int sum = 0; // BUG: 10^5 * 10^5 / 2 = 5 * 10^9
for (int i = 1; i <= n; i++) {
    sum += i; // OVERFLOW! int max is ~2 * 10^9
}

✅ Fix: Use long long

int n = 100000;
long long sum = 0; // Safe up to 9 * 10^18!
for (int i = 1; i <= n; i++) {
    sum += i; // No overflow!
}

❌ Bug 3: Backward loop with unsigned

// size_t is unsigned (never negative!)
for (size_t i = 5; i >= 0; i--) {
    // When i is 0, i-- wraps around to 18446744073709551615!
    // INFINITE LOOP! 💥
}

✅ Fix: Use signed int

for (int i = 5; i >= 0; i--) {
    // Cleanly stops when i becomes -1
}
